# IoT-project#
Based on your Unit 9: Project Management and Unit 19: Internet of Things assignment brief, I've created two different project timelines with tasks, deadlines and responsibilities.

Your project is to develop a functional arcade-themed cyber security awareness game for ages 8–18, using IoT technology, which could be showcased at the Cheltenham Science Festival.

I've divided the project into manageable stages so you we use the information in our project plan and Gantt chart.
Timeline 1 – 12-week project plan
Recommended
This timeline gives your team enough time for research, planning, designing, development and testing.
Week	Task	Activities
1.	Project initiation	Understand the client requirements, identify the problem and agree on project objectives.
2. Research	Research IoT technology, cyber security games and project management methodologies.
3.	Research solutions	Investigate at least two possible game ideas and compare their advantages and disadvantages.
4.	Feasibility study	Assess costs, time, resources and technical requirements. Select the best solution.
5.	Project planning	Allocate team responsibilities, create a project schedule and identify risks.
6.	Game design	Create storyboards, wireframes, interface designs and game layouts.
7.	IoT system design	Plan the IoT architecture, devices, communication methods and security.
8.	Prototype development	Start programming the game and building its main features.
9.	Feature development	Develop the scoring system, levels, instructions and player interactions.
10.	Testing	Test functionality, identify errors and collect feedback from users.
11.	Improvements	Fix bugs, improve the interface and make changes based on feedback.
12.	Final review	Evaluate the prototype, review client requirements and prepare the final presentation.

Timeline 2 – 8-week project plan
This is a shorter alternative if you have less time available.
Week	Task	Activities
1	Research and requirements	Research cyber security, IoT and client requirements.
2	Planning and feasibility	Compare two game ideas, select one and create the project plan.
3	Design	Create wireframes, storyboards and IoT architecture.
4	Initial development	Create the main menu, game screens and navigation.
5	Core development	Program the game mechanics, scoring and IoT features.
6	Testing	Test the game and identify technical problems.
7	Improvements	Fix errors, improve functionality and collect feedback.
8	Evaluation	Review the finished prototype and prepare the final presentation.


Team task allocation
You can also divide the work between different project roles so everyone has a responsibility.
Role	Main responsibilities
Project Manager	Create the timeline, organise meetings, monitor progress and manage deadlines.
System Architect	Plan the IoT system, architecture, devices and connections.
Electronics Engineer	Research and set up the hardware and electronic components.
Product Owner	Make sure the game meets the client's requirements.
Lead Developer	Manage the coding and support other developers.
Developer	Build the game, menus, levels and features.
Quality Assurance	Check that the game meets the requirements.
Test Lead	Organise testing and record test results.
QA Tester	Find bugs, test functionality and report problems.
IT Support Technician/User	Help with technical problems and test how easy the game is to use.
